consume it.

first paint, without touching the (already-correct, verified) desktop StickyNav behavior or any
non-homepage route's header.

gated on the homepage, matching CSS in globals.css, and navigation.test.tsx extended to cover all
three states (homepage hidden / homepage revealed / non-homepage always visible).

```
export function StickyNav() {
  const [show, setShow] = useState(false);

  useEffect(() => {
    const handleScroll = () => {
      setShow(window.scrollY > 24);
    };

    window.addEventListener("scroll", handleScroll, { passive: true });

    return () => {
      window.removeEventListener("scroll", handleScroll);
    };
  }, []);
```
Renders `<div className={`stickynav${show ? " show" : ""}`}>`. `useState`/`useEffect` are
imported from `"react"` at the top of this file and are used ONLY for this scroll listener --
removing them from this file's usage is safe once replaced by the hook.
