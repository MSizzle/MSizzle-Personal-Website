# Sketch 011: Hero Accent Treatments

Hero-only exploration of how far to push the accent color, from a spark to a full field.

## How to View
open .planning/sketches/011-hero-accent-treatments/index.html

Tabs switch treatment (caption bottom-left explains each); swatches bottom-right try colors.

## Variants
- A: Spark — accent only on eyebrow / link / dot.
- B: Accent word — one headline word colored.
- **C: Marker block ★** — the first line "Create Order" sits in a **solid accent block**
  that hugs the glyphs; "from Chaos" stays ink. Chosen.
- D: Accent field — portrait on a big accent panel + solid accent CTA.
- E: Bold rule — accent word + heavy accent underline bar + accent CTA.

## Outcome
**Winner: C (marker block).** Marker covers the whole first line and hugs the text
(line-height pulled in, tight padding). Accent = **vermilion**. Portrait column widened
to **44%**. This hero was ported verbatim into sketch 010 (the full-page spec).
