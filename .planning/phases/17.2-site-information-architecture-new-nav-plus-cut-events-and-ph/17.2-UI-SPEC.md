**Location:** `src/app/uses/page.tsx`  
**Current:** "Uses" page with 4 groups (AI & Development, Productivity, Communication, Hardware)  
**New (D-06):** Reframed as **"Things I Love"** with folded /watching section

#### Section Order (D-06)
1. **Tools** (renamed from "AI & Development")
2. **Books** (renamed from a subset; rename "Productivity" book-related items)
3. **Watching** (folded from /watching YouTube grid)
4. **Recommendations** (renamed from "Hardware" or create new; or merge misc)

#### UsesList Component Structure

**Component:** UsesList (`src/components/v3/uses-list.tsx`)  
**Current:** Takes `groups: UsesGroup[]` with `heading` + `items: {term, detail}[]`

**For Tools/Books/Recommendations sections:** Keep the existing dt/dd (definition-list) pattern with heading + term/detail pairs.

**For Watching section:** **New visual treatment** needed
- **Option A (Recommended):** Reuse VideoCard grid from /watching (3-column auto-fill at 320px minmax)
  - Embed VideoCard component within the Watching section
  - Provides visual variety, matches existing /watching aesthetic
  - Keep YouTube link behavior (target="_blank" rel="noopener noreferrer")
  
- **Option B (Fallback):** Use same dt/dd list for YouTube items (less visual, text-only)
  - Term = video title, detail = channel + link
  - Simpler but less engaging

**Recommendation:** Use Option A (VideoCard grid). Update /uses to import VideoCard and WATCHING_ITEMS, render Watching section as a grid-based subsection within UsesList or as a sibling section component.

#### Page Metadata


**Option A: Extend USES_DATA with 5th group**
