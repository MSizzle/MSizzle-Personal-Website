# Phase 17.2: Site Information Architecture - Context

**Gathered:** 2026-07-02
**Status:** Ready for planning

<domain>
## Phase Boundary

Restructure the site's information architecture to match the personal-brand arc: cut, fold, and merge routes; rebuild the primary nav and footer nav to the new set; and keep internal links + `sitemap.ts` + `robots` consistent with **no broken links**. This is an IA/routing rebuild in the **existing Pumpkin Amber skin** — NOT a restyle and NOT new content features.

**In scope:** route deletions + redirects, nav/footer link set, the /uses reframe (fold /watching), the /writing + /newsletter merge, sitemap/SEO consistency, fixing all internal links that pointed at cut/moved routes.

**Out of scope:** the homepage (done in 17.1), the portfolio build-out (Phase 17.3), any palette/type changes (aesthetic is locked), and net-new content pages.

</domain>

<decisions>
## Implementation Decisions

### Cut-route handling (SEO)
- **D-01:** Mixed strategy. **301-redirect** the public pages that may have inbound links; **hard-delete** the internal design-system pages (404).
  - `/events` → `/` (home) — 301
  - `/photos` → `/` (home) — 301
  - `/links` → `/about` — 301 (identity/connect context lives there; socials now woven into the footer)
  - `/specimen` → hard-delete, 404 (internal design-system page, never meant to be public)
  - `/v3-specimen` → hard-delete, 404 (same)
- **D-02:** Remove **all five** cut routes from `src/app/sitemap.ts`. The Phase 17 SEO regression gate must be updated so it no longer asserts these routes exist (avoid a false-negative regression).

### Writing + Newsletter merge
- **D-03:** `/writing` is the **canonical** merged "Writing / Monty Monthly" surface (it already holds the essay archive + canonical metadata + SEO history).
- **D-04:** `/newsletter` → **301 redirect to `/writing`**. Fold the Monty Monthly subscribe action + issue carousel into the /writing surface.
- **D-05:** Essay **posts stay at `/blog/[slug]`** — unchanged. `/blog` index behavior unchanged unless it conflicts; /writing remains the human-facing archive that links to /blog/[slug].

### /uses reframe ("Things I Love", fold /watching)
- **D-06:** One `/uses` page titled/reframed as "Things I Love", with sections in order: **Tools → Books → Watching → Recommendations**. This aligns with the homepage `SectionLoves` teaser (Tools/Books/Recommendations already link to /uses).
- **D-07:** Fold the existing `/watching` YouTube content into the **Watching** section of /uses. `/watching` → **301 redirect to `/uses`** (anchor `/uses#watching` acceptable if trivially supported, else plain `/uses`).

### Final nav structure
- **D-08:** Primary nav is **lean, 4 items: About / Projects / Writing / Uses**. `/prometheus` stays a dedicated page but is reached via the hero + About + Projects (woven), NOT in the primary nav — this fits the restraint / velvet-rope vibe.
- **D-09:** The **footer** carries the fuller set (About, Projects, Writing, Uses, Prometheus) **plus woven socials** (the /links fold). Footer and primary nav intentionally differ: nav is lean, footer is the complete map + "interface" layer.
- **D-10:** Update **both** `src/components/nav/navigation.tsx` and `src/components/layout/v3-footer.tsx` to the new sets; remove every link to a cut route (events/photos/links/specimen/v3-specimen/newsletter/watching) across the codebase.

### Claude's Discretion
- Exact redirect mechanism (Next.js `redirects()` in config vs per-route `redirect()` / middleware) — planner/researcher picks the idiomatic Next 16 approach; requirement is that the 301s above resolve and the deleted routes 404.
- Whether `/uses#watching` deep-link is wired (nice-to-have, not required).
- Copy/heading wording for the reframed /uses and merged /writing surfaces (keep current voice).

</decisions>
