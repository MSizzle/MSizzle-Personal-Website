# Phase 17.4 Plan 02: Presentational Primitives (RailBox, Photo, CredibilityStrip) Summary

Three hard-cornered Server Component primitives — RailBox (D-05), Photo (D-07), CredibilityStrip (D-11) — built against Plan-01 CSS classes, ready for Wave-3 section and hero consumers.

## What Was Built

1. **RailBox** (`src/components/home/rail-box.tsx`) — Auto-inverting index+label box (D-05). Renders `.rail > .rail-box > .num + .lbl`. Background `var(--color-text)` / color `var(--color-bg)` means it naturally flips to white-on-dark inside `.band-dark` and black-on-white in light bands — one component, two appearances, zero JS. Props: `num: string`, `label: string`.

2. **Photo** (`src/components/home/photo.tsx`) — Placeholder photo block (D-07). Renders `.photo[.dark][.breathe]` with an inner `.img.kenburns`, a `◲` icon glyph, and an optional `.cap` caption. `dark` and `breathe` are boolean props that toggle the corresponding CSS classes; the actual animation and inversion logic lives entirely in Plan-01 CSS (reduced-motion gated). `aspectRatio` flows to a `style` prop for user-supplied values. Props: `caption?`, `dark?`, `aspectRatio?`, `breathe?`, `className?`.

3. **CredibilityStrip** (`src/components/home/credibility-strip.tsx`) — "As seen in" placeholder logo strip (D-11). Renders `.proof > .lbl + .marks` with five `.m Logo` placeholder marks. Keep-or-cut deferred to real-asset swap. Label uses middot, not em dash, per site copy rules.

## Deviations from Plan

None — plan executed exactly as written.

All acceptance criteria met:
- `rail-box.tsx` exports `RailBox` with `num`/`label` props, emits `.rail-box > .num + .lbl`, no `"use client"`.
- `credibility-strip.tsx` exports `CredibilityStrip`, emits `.proof > .lbl + .marks` with 5 `.m` marks, no em dash.
- `photo.tsx` exports `Photo` with all five documented props, emits `.photo[.dark][.breathe] > .img.kenburns + .icon + .cap`, no `"use client"`.
- `npx tsc --noEmit` — only pre-existing test file errors (uses.test.tsx, robots.test.ts, documented in Plan 01); no new errors introduced.

## Known Stubs

- **CredibilityStrip `.m` marks** — five `<div className="m">Logo</div>` placeholders. Intentional (D-11 defers real logos to real-asset swap). Marked for Wave-N keep-or-cut.
- **Photo `.img.kenburns` div** — no real image source; renders the CSS hatch background from Plan-01. Real photography replaces this in a later swap (blocked on final visual sign-off per CONTEXT.md).

These stubs do not prevent the plan goal: the primitives expose the correct component contracts for Wave-3 consumers.

## Threat Flags

None. All three are static Server Components emitting fixed placeholder markup. No user input, no network fetch, no auth paths.
