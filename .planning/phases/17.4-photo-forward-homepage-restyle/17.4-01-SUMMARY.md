# Phase 17.4 Plan 01: Design Token Foundation & CSS System Summary

Vermilion token palette (D-01), Hanken Grotesk 800 (D-02), and the full sketch-010 CSS class library (band inversion D-03, hard corners D-04, rail box D-05, photo/motion D-07, reduced-motion D-08) are in place and the project builds cleanly.

## What Was Built

A complete CSS design substrate for the photo-forward homepage restyle:

1. **Ink + Vermilion palette** — The site-wide `@theme inline` block now uses near-white paper `#faf9f7` + near-black ink `#171717` + vermilion accent family (`#e5411f`/`#c8381a`/`#a52d13`). Zero cobalt or amber hex remain. `--sig-shadow` updated to use `var(--accent)` for a hard vermilion drop shadow on the signature treatment.

2. **Hanken Grotesk 800** — `layout.tsx` now loads Hanken_Grotesk via next/font (weights 400/500/700/800, CSS var `--font-hanken`). Space Grotesk completely removed (zero remaining references). `--font-display` and `--font-sans` both repoint to `--font-hanken`, making Hanken the site-wide display + body font.

3. **Band inversion mechanism** — `.band-dark` locally re-declares `--color-text`, `--color-text-dim`, `--color-text-muted`, `--color-border`, `--color-border-strong`, and `background:#141416`. Because Tailwind v4 `@theme inline` emits utilities that read CSS vars at use-site, all token-class children (`.text-text`, `.bg-bg`, `.border-border`) auto-invert inside a `.band-dark` wrapper without per-component changes.

4. **Full CSS class library** (677 lines appended) — Every class the sketch-010 homepage references: `.eyebrow`, `.marker`/`h1.sig .hw`, `.blob`, `.photo` system, `section.beat`/`.beat-grid`, `.rail-box`, `.statustag`/`.dot`, drift/pulse/slide/kb/breathe keyframes, `.hero-ticker`, `.beat h2`/`p.body`/`.inline`, `.work-grid`, `.marquee`, full `.mm-*` carousel suite, `.stickynav` (z-index 9000), `.proof`/`.m`, `.avail`/`.foot-grid`/`.foot-col`, `.reveal`/`.slide`/`.shadowed` even-shadow settle, `.kenburns`/`.breathe`.

5. **Reduced-motion guards** — Both `body.no-motion` (JS-togglable escape hatch) and `@media (prefers-reduced-motion: reduce)` force `.reveal`/`.slide` to `opacity:1; transform:none` and kill all ambient keyframes. Static layout remains intact in all motion-disabled paths (D-08).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Applied full Ink palette migration in Task 1**
- **Found during:** Task 1
- **Issue:** The plan assumed the ink-cobalt palette (`#faf9f7` paper + `#171717` ink) had been committed before this plan ran. The actual committed state was the superseded Pumpkin Amber palette (`#ff7a14`, teal accent). The ink-cobalt changes were applied locally but never committed (project memory: "uncommitted pending sign-off").
- **Fix:** Combined the ink-cobalt base migration AND the cobalt→vermilion swap into a single `@theme inline` rewrite in Task 1. End result is identical to the plan's intent; the path through "cobalt" was skipped because that state never existed in git.
- **Files modified:** `src/app/globals.css`
- **Commit:** f5844d1

**2. [Rule 2 - Critical] Added .hero-ticker .track to reduced-motion guards**
- **Found during:** Task 3
- **Issue:** The plan's D-08 reduced-motion spec targeted `.marquee .track` but the hero ticker uses `.hero-ticker .track` which is a separate animation. Without the guard, the hero ticker would still animate for users with reduced-motion preference.
- **Fix:** Added `.hero-ticker .track` to both the `body.no-motion` block and the `@media (prefers-reduced-motion: reduce)` block.
- **Files modified:** `src/app/globals.css`
- **Commit:** 98de96d

**3. [Rule 2 - Critical] Added .marker generic alias**
- **Found during:** Task 3
- **Issue:** Plan referenced both `.marker` and `h1.sig .hw` but sketch only defines `h1.sig .hw`. Added `.marker` as a generic alias since downstream components may need a standalone marker class.
- **Fix:** Combined `.marker, h1.sig .hw { ... }` rule.
- **Files modified:** `src/app/globals.css`
- **Commit:** 98de96d

**4. [Rule 2 - Critical] Added --ease-out to :root**
- **Found during:** Task 3
- **Issue:** The sketch CSS uses `var(--ease-out)` in motion transitions (`.reveal`, `.slide`, `.shadowed`) but the variable is defined in `ink-cobalt.css` which is an external theme file not part of this repo. Without it, transitions would fall back to the browser default `ease`.
- **Fix:** Added `--ease-out: cubic-bezier(0.22, 1, 0.36, 1)` (easeOutQuint) to `:root`.
- **Files modified:** `src/app/globals.css`
- **Commit:** 98de96d

**5. [Out of scope] Pre-existing TypeScript errors in test files**
- `src/__tests__/pages/uses.test.tsx` and `src/__tests__/seo/robots.test.ts` have pre-existing TypeScript errors (verified: same errors exist on the commit prior to this plan). These are unrelated to this plan's changes. Logged to deferred-items.

### Intentional Scoping Decision

`.beat h2` was scoped to `.beat` wrapper rather than a bare `h2` selector (as in the sketch). The sketch's bare `h2` would override heading styles on interior pages (blog, portfolio, about). The scoped selector provides the same result on homepage sections without side effects.
