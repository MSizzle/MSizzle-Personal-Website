<decisions>
## Implementation Decisions

Every decision below is LOCKED (chosen with Monty across sketch rounds 007→011 on 2026-07-04) unless
marked. `.planning/sketches/010-structured-bands-carousel/index.html` is the authoritative visual
reference for exact structure, spacing, and interaction — read it before planning or implementing.

### Palette / Tokens
- **D-01:** Re-theme the accent from cobalt `#1a4fd6` to **Vermilion `#e5411f`** in `src/app/globals.css`.
  Token-only edit: update `--accent`, `--accent-hover`, `--accent-deep`, `--accent-glow`, the
  `--color-accent*` aliases, `--blob-rim`, and the `.sig` shadow (`--sig-shadow`) to the vermilion
  family. Near-white paper (`--color-bg #faf9f7`) and near-black ink (`--color-text #171717`) base
  are RETAINED. No cobalt accent may remain on the home path.

### Typography
- **D-02:** Display type is **Hanken Grotesk 800**, wired via `next/font/google` in
  `src/app/layout.tsx` (new font instance with a CSS variable, e.g. `--font-hanken`), and mapped in
  globals so `--font-display` (and `--font-sans` for body/labels per the sketch) resolve to Hanken.
  Space Grotesk is replaced for display; JetBrains Mono is retained for mono. Rejected en route
  (real signal, do not re-propose): Space Grotesk, Clash/Cabinet, Geist, serif options.

### Structure
- **D-03:** Full-page single column of **alternating light/dark bands** in this order:
  hero (light) → credibility strip (light) → Building (dark) → Work (light) → Things I Love (dark)
  → Writing (light) → footer (dark). Maps onto the existing section components
  (Building/Work/Loves/Newsletter→Writing/Footer), re-skinned and re-ordered per the sketch.
- **D-04:** **Hard corners (radius 0) everywhere** — photos, cards, buttons, boxes.
- **D-05:** **Rail boxes** on sections — an index number + label inside an auto-inverting
  high-contrast box (inverts against the band it sits on).

### Hero
- **D-06:** Hero = big two-line headline: **"Create Order"** in a **solid vermilion marker block**
  hugging the glyphs, **"from Chaos"** in ink. A large **44%-width portrait column** (placeholder
  block now; ken-burns "breathe" drift). A black **status tag** ("Currently — building Prometheus").
  A full-bleed **black marquee strip** of section links **pinned to the base of the hero viewport**
  (the marquee lives on the hero, not the footer).

### Photos / Motion
- **D-07:** Large photos **slide in from the side** on scroll (alternating L/R), settling with an
  **even black drop-shadow** (not an angled frame). Ken-burns drift on photos + hero portrait
  "breathes." Placeholder blocks stand in for real photography.
- **D-08:** **Motion is scroll-triggered + ambient only — never cursor-dependent.**
  `prefers-reduced-motion` is honored and a motion on/off state must leave the static layout intact.
  Use IntersectionObserver + CSS + native scroll-snap. **No WebGL, no Lenis, no heavy scroll stack**
  on the home render path.

### Writing / Newsletter
- **D-09:** The Writing section is a horizontal **Monty Monthly carousel** — issue cards + a subscribe
  card, with arrows + dots + native scroll-snap. The newsletter is a **link-out to Substack**; there
  is **no on-site email capture**.

### Professional Layer
- **D-10:** **Sticky mini-nav** with a persistent **Subscribe CTA** that appears past the hero.
- **D-11:** **"As seen in" credibility strip** with placeholder logos (keep-or-cut is deferred to
  the real-asset swap).
- **D-12:** Multi-column **footer** (colophon / navigate / elsewhere) with an **"Available for select
  work"** tag.

### IA / Engagement (preserved from 17.1/17.2 — re-skinned, not changed)
- **D-13:** Velvet-rope engagement is preserved: **no contact page, no contact CTA button**; Monty
  Monthly is the primary woven "way in"; who → what → engage arc content is retained. This restyle
  changes presentation, not IA.

### Claude's Discretion
- Exact component decomposition (which section files to rewrite vs. add, how to split the hero and
  carousel into client islands) — subject to keeping `/` a static Server Component shell with the
  smallest possible client surface (carousel + scroll reveals only).
- Placeholder treatment for photos/logos (labeled blocks matching the sketch's placeholder style).
- Reduced-motion implementation details, as long as D-08 holds.
- Perf approach specifics, as long as the existing LCP/PSI gates (Phase 18) are respected and no
  WebGL/Lenis is added to the home path.

</decisions>
