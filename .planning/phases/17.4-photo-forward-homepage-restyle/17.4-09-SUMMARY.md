## Task 2 — Human visual verification: APPROVED (after iteration)

Verified live at localhost:3000 against sketch 010. Monty's review surfaced several
issues, each fixed and re-verified in-browser before sign-off:

1. **D-03 dark bands not rendering (blocker).** `.band-dark` set inverted text tokens but
   its dark `background` lost the cascade to the later equal-specificity `.band` rule →
   near-white text on near-white bands (bands looked empty). Fixed by matching dark
   sections via `.band.band-dark` (higher specificity). `#building`/`#loves` now compute
   `rgb(20,20,22)`. This restored the alternating light/dark rhythm — the core of sketch 010.
2. **Hero marquee too small.** Executor shipped an 11px uppercase strip; the approved
   sketch uses display type (Hanken 800, `clamp(1.4rem,3.6vw,2.7rem)`). Restored to spec.
3. **Hero portrait too narrow.** Widened the column (44%→52%, center-aligned) and gave it a
   5/6 aspect box (wider/shorter, not a full-height sliver).
4. **Portrait crossfade.** Portrait is now a CSS-only 3-slide crossfade (~6s each, 18s loop),
   reduced-motion-safe (settles to first slide). Stays a Server Component.
5. **Headline treatment.** Removed the vermilion text-shadow; "Create Order / from Chaos"
   now sits on a solid white card with a **hard 12px ink offset block** (brutalist, D-06).
6. **Marquee below the fold.** Reduced hero to 86dvh so the marquee lands in a normal viewport.
7. **Cut the "as seen in" CredibilityStrip** (no press to show; component kept dormant) and
   the footer "Available for select work / I take on very little…" reach-out block (tightens
   velvet-rope, D-13).
8. **Broken popups repaired.** The v3 palette migration orphaned the legacy
   `--bg/--border/--text` tokens still used by `visit-survey`, `navigation`, and several
   blog/about surfaces → transparent (invisible over dark bands). Added root back-compat
   aliases → `--color-*`; the VisitSurvey popup is now solid and legible.
9. **No gradients site-wide → offset solid shapes (brutalist).** Replaced every on-page
   gradient with solids (photo placeholders, carousel tints, removed the radial-gradient
   blob, solid captions + sticky-nav), and converted soft shadows to hard offset solids
   (headline ink block; `.shadowed` photo settle = 16px offset using `--color-text` so it
   auto-inverts per band). Verified zero gradient backgrounds in the rendered DOM.
10. **Warm cream hero.** Hero band uses `--hero-bg: #f4ecdd` so the white headline card
    stands out; complements the vermilion. Other light bands stay on paper.
