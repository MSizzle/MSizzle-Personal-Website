# Phase 17.4 Plan 05: Marker-Block Hero Summary

Sketch-010 hero (D-06) built as a static Server Component: Vermilion marker "Create Order / from Chaos" headline, 44% breathing portrait column (Photo primitive), black status tag with pulsing dot, single Monty Monthly way-in (D-13), and a full-bleed black section-link marquee pinned to the hero base (D-08 ambient CSS only).

## What Was Built

**`src/components/home/hero.tsx`** - A Server Component (no `"use client"`, no GL imports) that renders the complete sketch-010 hero layout:

1. **Section wrapper** - `section.band.hero-band.min-h-[100dvh].flex.flex-col` provides the full-viewport light band structure.

2. **Hero grid** - `.wrap` content container (max-width 1180px, clamp padding) contains a `.hero` two-column grid (1fr + minmax(320px, 44%)) matching the sketch split ratio.

3. **Copy column** - Eyebrow "Founder of Prometheus", `h1.sig` with `.hl` / `.hw` spans ("Create Order" in solid Vermilion marker, "from Chaos" in ink), `.subtitle` paragraph, `.wayin` way-in link to `#writing` ("Join Monty Monthly"), `.statustag` with pulsing `.dot`.

4. **Photo column** - `<Photo breathe caption="Large portrait" />` fills the column via `.hero .col-photo .photo` CSS (min-height 56vh, width/height 100%).

5. **Ambient blob** - Absolutely positioned within the section, coordinates from sketch (top:2%, right:34%).

6. **Pinned hero ticker** - `.hero-ticker > .track` containing two duplicate groups of 5 section-link anchors (Building, Work, Writing, Things I Love, Uses) for seamless CSS `slide` animation loop.
