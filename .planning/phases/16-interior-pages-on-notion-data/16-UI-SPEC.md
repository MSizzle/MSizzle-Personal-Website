## Spacing Scale

Declared values (source: v3 globals.css and prototype 002; multiples of 4):

| Token | Value | Usage | Reference |
|-------|-------|-------|-----------|
| xs | 4px | Icon gaps, inline padding; element borders | --color-border, --color-border-strong |
| sm | 8px | Compact element spacing within cards; mono letter-spacing baseline | font-mono class baseline |
| md | 16px | Default element spacing; card title margins; grid gaps in some contexts | Card padding, photo grid gaps |
| lg | 24px | Section padding top/bottom; page-hero margins | --space-24 in prototype |
| xl | 32px | Layout gaps; between major sections | Used in footer columns |
| 2xl | 48px | Major section breaks; footer top margin | --space-32 in prototype |
| 3xl | 64px | Page-level spacing; clamp padding | --space-64 implied by max-width rules |

### Critical Spacing Details

- **Page-hero top padding:** `clamp(90px, 16vh, 180px)` (responsive, respects viewport height for interior pages)
- **Page-hero bottom padding:** 3xl / 48px
- **Card padding:** 26px (explicit, not on 4px scale but production value)
- **Photo-grid gap:** 1px (border acts as divider; grid uses `bg-border` for gutter)
- **Writing/Works rows:** 22px vertical padding; 18px horizontal (forms a tight row clickable area)
- **Uses list grid columns:** 200px (term) + 1fr (detail); gap-x-6 (24px); collapses to single column below 600px
- **Video-grid gap:** 22px (between cards, larger than photo-grid for breathing room)

Exceptions: **26px card padding, 22px row padding, 22px video-grid gap** are precise production values (not multiples of 4) — use exactly as specified.

### Accent Reserved For (10% of design, SPARINGLY)

- **Hyperlinks in prose** (a.text-accent, text-decoration: underline)
- **Breadcrumb separators** (span.sep, color: var(--accent))
- **Kicker labels** (Card .k, .mono.text-accent)
- **Section labels** (.slabel, .mono.text-accent)
- **Active nav links** (.links a.active)
- **Play triangles** (VideoCard hover state)
- **Hover accents** (hover:bg-accent; group-hover:border-l-accent)
- **Blockquote borders** (.prose blockquote border-left: 2px solid var(--accent))
- **Special emphasis dots** (.meta-row .dot, color: var(--accent))

Do NOT use accent for:
- Buttons (use bg-text / border-border, invert on hover)
- Card backgrounds (use bg-bg, hover to bg-bg-2)
- Body text (use text-text or text-text-dim)

### No Second Semantic Color (Destructive)

Interior pages have no delete/destructive actions. Confirmation and error states are handled via prose copy only (no special color treatment). Keep single accent teal.

```
https://img.youtube.com/vi/{videoId}/hqdefault.jpg  (480x360, preferred)
https://img.youtube.com/vi/{videoId}/sddefault.jpg  (640x480, fallback)
```

**Next.js Image usage:**
```tsx
<Image
  src={`https://img.youtube.com/vi/${item.id}/hqdefault.jpg`}
  alt={item.title}
  width={480}
  height={360}
  sizes="(max-width: 600px) 100vw, (max-width: 1024px) 50vw, 33vw"
/>
```

**Requirement:** Add to `next.config.ts` remotePatterns:
```typescript
{
  protocol: "https",
  hostname: "img.youtube.com",
}
```

## Animation & Motion

**From D-01:** Interior pages are **calm + reading-first**. Animations are **subtle**, **respect reducedMotion**, and **never distract from content.**

### Allowed Animations

1. **Scroll-reveal fades:** `.reveal` class on cards + prose sections
   - Opacity: 0 → 1
   - Transform: translateY(30px) → none
   - Duration: 0.9s ease-out
   - **Trigger:** Intersection Observer (on scroll into view)
   - **Respects reducedMotion:** disables if `prefers-reduced-motion: reduce`

2. **Hover transitions:**
   - Card background: amber → deeper amber (150ms)
   - Video card lift: translateY(0) → translateY(-4px) (150ms)
   - Nav link color fade (150ms)
   - **Must be instant on touch (no hover state on mobile)**

3. **No autonomous animations:** No marquees, no looping keyframes, no animated type on interior pages (those are homepage-only per D-01)

### Implementation

```css
/* Global reveal animation (in globals.css or component) */
.reveal {
  opacity: 0;
  transform: translateY(30px);
  transition: opacity 0.9s var(--ease-out), transform 0.9s var(--ease-out);
}

.reveal.in {
  opacity: 1;
  transform: none;
}

/* Triggered via IntersectionObserver or Motion library */
@media (prefers-reduced-motion: reduce) {
  .reveal, .reveal.in {
    opacity: 1;
    transform: none;
    transition: none;
  }
}
```

**Preflight check (D-01 locked):** Interior pages do NOT use Motion keyframes for autonomous animation. Use Motion only for user-triggered interactions (scroll-reveal via Intersection Observer, hover states).
