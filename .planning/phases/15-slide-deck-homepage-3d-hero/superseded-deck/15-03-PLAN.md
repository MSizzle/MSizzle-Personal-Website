<!-- From prototype site.js initBlob() lines 72-103 — the behavioral spec -->

Geometry: THREE.IcosahedronGeometry(1.3, 12) for blob; THREE.IcosahedronGeometry(1.35, 2) for wire overlay
Base positions: Float32Array slice of geo.attributes.position.array taken once on mount (useMemo)

Sine-sum morph (per frame, prototype lines 90-98):
  t += 0.006 per frame
  for each vertex i:
    bx=base[i*3], by=base[i*3+1], bz=base[i*3+2]
    l = hypot(bx,by,bz) || 1
    n = sin(bx*2 + t*1.6) + sin(by*2.3 + t*1.2) + sin(bz*2.1 + t*1.9)
    d = 1.3 + n*0.11
    pos.array[i*3]   = (bx/l)*d
    pos.array[i*3+1] = (by/l)*d
    pos.array[i*3+2] = (bz/l)*d
  pos.needsUpdate = true; geo.computeVertexNormals()

Autonomous rotation (prototype line 100):
  blob: rotation.y += 0.0035; rotation.x = sin(t*0.3)*0.22
  wire: rotation.y -= 0.0018; rotation.z += 0.001

Light rig (RESEARCH.md Pattern 3 / PATTERNS.md hero-blob-canvas.tsx):
  directionalLight color=0xffffff intensity=1.9 position=[3,4,5]       (key)
  directionalLight color=0xff6a3a intensity=1.7 position=[-4,-2,-4]    (crimson rim)
  directionalLight color=0xffffff intensity=0.45 position=[-3,2,3]     (fill)
  ambientLight color=0x1a0a06 intensity=0.5

Material (D-04 elevated from prototype's MeshStandardMaterial):
  meshPhysicalMaterial: color=0x140805, metalness=0.6, roughness=0.18,
  clearcoat=0.9, clearcoatRoughness=0.1, envMapIntensity=1.2

Wire material: meshBasicMaterial wireframe=true opacity=0.16 transparent=true color=0x333333

R3F Canvas gl defaults (R3F v9 — DO NOT override):
  outputColorSpace = SRGBColorSpace (default)
  toneMapping = ACESFilmicToneMapping (default)
