| WebGL context creation | Uses failIfMajorPerformanceCaveat: true to prevent software renderer fingerprinting |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-08 | Information Disclosure | WebGL2 + GPU capability detection via getContext("webgl2") | mitigate | failIfMajorPerformanceCaveat: true already in gate code (carried verbatim from deck-homepage.tsx); prevents software renderer and reduces GPU fingerprinting surface |
