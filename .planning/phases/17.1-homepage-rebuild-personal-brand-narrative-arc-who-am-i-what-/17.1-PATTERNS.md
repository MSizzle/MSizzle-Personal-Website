## Shared Patterns

### Section Wrapper Structure
**Apply to:** All section components (building, writing, newsletter, footer, any new sections)

**Core pattern** (from existing sections):
```typescript
<section className="min-h-dvh flex flex-col justify-center px-[8vw] py-[15vh]">
  {/* Content */}
</section>
```

**Variants:**
- Footer section: `min-h-[40vh]`, `justify-end` (shorter, pinned to bottom)
- All others: `min-h-dvh`, `justify-center` (full viewport, vertically centered)

**Token classes:**
- `px-[8vw]` — horizontal padding (8% viewport width, maintains full-width amber field)
- `py-[15vh]` — vertical padding (proportional to viewport height)
- `flex flex-col` — vertical stack
- Section labels use `text-accent` (teal accent on amber background)
- Body text uses `text-text` (roasted cocoa ink on amber), `text-text-dim` for secondary, `text-text-muted` for tertiary
- Links use `text-text hover:text-accent` pattern

---

### Display Text / Signature Treatment
**Apply to:** All large headlines, feature text, hero elements

**Filled signature** (`.sig` class):
```typescript
<h1 className="font-display font-bold uppercase sig text-[clamp(...)] leading-[0.9]">
  Text here
</h1>
```

**Token classes:**
- `.sig` — roasted cocoa ink fill + cream drop shadow (from globals.css lines 76-90)
- `font-display font-bold uppercase` — large display face, bold weight, all caps
- `text-[clamp(...)]` — responsive sizing (e.g., `clamp(2rem,6vw,4rem)` for medium, `clamp(2.8rem,11vw,8rem)` for large)
- `leading-[0.9]` or `leading-[0.86]` — tight line height (display type)
- `tracking-[-0.03em]` — tight letter spacing (tightens large type)

**Outline variant** (`.sig-out` class):
```typescript
<span className="sig-out">Text here</span>
```

**Token classes:**
- `.sig-out` — teal stroke, transparent fill (from globals.css lines 81-85)
- Used for hover states or emphasis variants
