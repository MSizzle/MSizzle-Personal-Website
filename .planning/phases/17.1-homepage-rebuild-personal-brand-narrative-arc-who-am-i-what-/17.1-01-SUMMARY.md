# Phase 17.1 Plan 1: Blob Gate Removal and Text-Forward Hero Summary

**One-liner:** Converted `explorative-homepage.tsx` from a `"use client"` WebGL gate orchestrator to a Server Component with a text-forward hero anchored on "Founder of Prometheus" and a woven Monty Monthly subscription invite.

## What Was Built

`explorative-homepage.tsx` was fully rewritten:

- Dropped `"use client"` directive, making it a plain Server Component
- Removed all React hooks (`useState`, `useEffect`, `useReducedMotion`)
- Removed `CanvasLoader`, `FallbackPoster`, and the blob gate logic (`isTouchOrSmall`, `webglOk`, `showCanvas`)
- Added `next/link` import for outbound link safety
- Replaced the `relative/absolute` canvas hero section with a clean `min-h-dvh flex flex-col justify-center px-[8vw]` section
- Hero h1: "Founder of Prometheus" in `font-display font-bold uppercase sig text-[clamp(2.8rem,11vw,8rem)] leading-[0.9] tracking-[-0.03em]`
- Subtitle p: "Building a company. Writing about what I am learning." in `text-text-dim font-display`
- Woven Monty Monthly p: prose-style invite with `next/link` to `https://montymonthly.substack.com`, `target="_blank"`, `rel="noopener noreferrer"`, `hover:text-accent transition-colors duration-150`
- Outer container class renamed from `explorative-homepage` to `personal-homepage`
- Four existing section imports (SectionBuilding, SectionWriting, SectionNewsletter, SectionFooter) preserved intact for Plan 17.1-02

`page.tsx` JSDoc was updated to describe the personal-brand narrative arc purpose. No structural changes — `revalidate = false`, `JsonLd`, and `ExplorativeHomepage` import all preserved.
