Gaps to address in this plan:
- The manifesto h1 still uses `text-display uppercase text-ink` only (Plan 10-01) — no mobile override. Needs `text-[56px] leading-[0.96] tracking-[-0.045em] md:text-display` or equivalent (D-32).
- The mobile manifesto is `["BRING", "FIRE TO", "HUMANITY."]` per D-32 REVISED — but Plan 10-01 hard-coded the 2-line desktop layout. Three approaches per RESEARCH §"Mobile Manifesto Line-Break Recommendation":
  - (a) Render two `<h1>` blocks with hidden/visible toggles (simple, single render path).
  - (b) Defer the line-break decision to Plan 10-07's `<ManifestoReveal>` component (cleaner — one client component owns both layouts via matchMedia).
  - (c) CSS-only line breaks (hard with per-letter spans in Plan 10-07).
- Recommended for THIS plan: keep the desktop static markup unchanged (Plan 10-01's `<h1>` with two `<span>` lines), but ADD `class="hidden md:block"` to the desktop h1 AND render a SECOND `<h1 className="md:hidden ...">` with the 3-line mobile version. Plan 10-07 then replaces the static markup with `<ManifestoReveal>` and handles the responsive lines internally (per the matchMedia approach in 10-RESEARCH §"Mobile Manifesto Line-Break Recommendation" → "Approach #2").
- PHOTOGRAPHS grid: Plan 10-04 used `grid-cols-12 grid-rows-[180px] gap-3` unconditionally. Add mobile override: `grid-cols-2 grid-rows-[auto] gap-2 md:grid-cols-12 md:grid-rows-[180px] md:gap-3`. Each plate's `${p.span}` (which contains `col-span-N row-span-M`) needs to apply only at md: — wrap the spans with `md:` prefix. Per-plate class becomes `relative ${p.span.replace(/(col-span|row-span)/g, 'md:$1')}` — but for clarity, restructure HOME_PHOTOS so the spans are mobile + desktop pairs (recommended below in action).
- Header (Plan 10-01): already uses `px-6 pt-7 md:px-40 md:pt-9` — mobile size for the 5-link nav needs verification. Add `min-h-11` to each nav link to guarantee 44px tap targets per D-32. Also consider whether the 5 inline links fit at 390px — if not (likely tight), wrap with `flex-wrap gap-x-6 gap-y-2`. Decision: keep horizontal flex with `flex-wrap` + `gap-x-6 gap-y-2` so very narrow viewports can wrap to two rows gracefully.
- Footer (Plan 10-05): the 4-column grid is already `grid-cols-1 md:grid-cols-4` (single column on mobile). Add per-column hairline divider on mobile only — each FooterCol-level wrapper gets `border-b border-footer-rule pb-6 md:border-b-0 md:pb-0`. Since FooterCol itself is a primitive component, wrap each FooterCol invocation in a `<div>` with these classes.
