hardcoded hex survivals, and one unified `:focus-visible` rule.

branch. The repo is currently on `main` with no `v4-mono` branch yet. Task 1 below creates it. Every
subsequent plan in this phase (20-02 through 20-05) commits directly to this same branch/working tree —
do not create a separate worktree branch per plan, and do not merge any individual plan back to `main`.
