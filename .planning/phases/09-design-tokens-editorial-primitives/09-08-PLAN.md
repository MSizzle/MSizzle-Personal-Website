- No 'use client' directive (D-11 — Server Component).
- Import `Link` from `'next/link'`.
- Define types:

    type FooterLink = { label: string; href: string; sub?: string }
    type Props = { title: string; links: FooterLink[] }

- Named export `FooterCol({ title, links }: Props): JSX.Element`.
- Render structure:

    <div>
      <div className="text-label uppercase text-footer-fg">{title}</div>
      <ul className="mt-6 space-y-3">
        {links.map((link) => (
          <li key={link.href}>
            <Link
              href={link.href}
              className="text-nav text-footer-fg transition-opacity duration-100 hover:opacity-70"
            >
              {link.label}
            </Link>
            {link.sub && (
              <div className="mt-1 text-nav text-footer-mute">{link.sub}</div>
            )}
          </li>
        ))}
      </ul>
    </div>

Token breakdown (every class is token-driven or standard scale):
  - Title row: `text-label uppercase text-footer-fg` — 11px / 0.2em tracked / 700 weight (D-06) in footer-fg color (paper on ink — D-01)
  - List spacing: `mt-6 space-y-3` — standard Tailwind spacing scale (mt-6 = 24px between title and links; space-y-3 = 12px between link items)
  - Link label: `text-nav text-footer-fg` — 13px / 0.02em tracked (handoff Nav row) in paper foreground
  - Hover affordance: `transition-opacity duration-100 hover:opacity-70` (same pattern as AllLink; matches handoff's 120ms underline state in spirit even though FooterCol's links are not underlined)
  - Sub-line: `mt-1 text-nav text-footer-mute` — small top margin (4px) + same 13px nav size + footer-mute color (#7A7770) for the grey sub-line

Use the link's `href` as the React key since each link href is expected to be unique within a column (e.g., "/about", "/newsletter"). Consumer is responsible for unique hrefs within a single FooterCol instance.

Zero arbitrary values (D-09). All color tokens are from the v2.0 footer palette (D-01).
