Create `src/components/editorial/intro-link.tsx`:

- No 'use client' directive (D-11 — Server Component).
- Import `Link` from `'next/link'`.
- Define `type Props = { href: string; children: React.ReactNode }`.
- Named export `IntroLink({ href, children }: Props): JSX.Element`.
- Render a `<Link href={href}>` with className:

  `border-b border-ink text-ink`

That's it. Three classes:
  - `border-b border-ink` — 1px ink bottom-border (the documented affordance)
  - `text-ink` — explicit foreground color (inherits from paragraph but stating it makes the intent obvious and prevents accidental drift)

Deliberate omissions (the editorial restraint):
  - NO `hover:` variant — handoff says "no color shift" and PRIM-06 confirms (different from AllLink's hover:opacity-70)
  - NO `inline-block` — IntroLink is INLINE inside paragraph prose; inline-block would break text wrapping mid-link
  - NO `uppercase`, NO `font-bold` — inherits the body-lead 400 weight from the surrounding paragraph
  - NO `text-nav` or other size token — inherits the parent paragraph's text-body-lead size
  - NO `pb-1` — when inline, padding-bottom would lift the link off the baseline and break the prose rhythm

The minimal reference component:

  export function IntroLink({ href, children }: Props) {
    return (
      <Link href={href} className="border-b border-ink text-ink">
        {children}
      </Link>
    )
  }

Zero arbitrary values (D-09). The simplicity is the point: IntroLink is the minimal inline-link affordance — anything more breaks the editorial reading rhythm of the letter-style intro paragraph.
