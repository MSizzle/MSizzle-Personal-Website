  `inline-block border-b border-ink pb-1 text-nav font-bold uppercase text-ink transition-opacity duration-100 hover:opacity-70`

Token breakdown (every class is token-driven or standard scale):
  - `inline-block` — required so the border-b sizes to the text width
  - `border-b border-ink` — 1px ink bottom-border (handoff's "1px ink bottom border")
  - `pb-1` — 4px padding-bottom (standard Tailwind spacing increment; D-09-compliant choice from RESEARCH.md Pattern 3 note over the arbitrary pb-[3px])
  - `text-nav` — 13px / 0.02em tracked (handoff's Nav row; closest editorial token for the AllLink size)
  - `font-bold` — promotes text-nav from 400 to 700 weight; handoff shows AllLink as bold uppercase
  - `uppercase` — text-transform
  - `text-ink` — foreground color (#0E0E0C)
  - `transition-opacity duration-100 hover:opacity-70` — hover affordance (handoff §Hover: 120ms ease; Tailwind duration-100 is 100ms — close to spec and token-aligned)

Children are the full link text including the trailing arrow (e.g., the consumer passes `<AllLink href="/writing">All writing →</AllLink>`).

The full reference component:

  export function AllLink({ href, children }: Props) {
    return (
      <Link
        href={href}
        className="inline-block border-b border-ink pb-1 text-nav font-bold uppercase text-ink transition-opacity duration-100 hover:opacity-70"
      >
        {children}
      </Link>
    )
  }

Zero arbitrary values: no `border-[1px]`, no `pb-[3px]`, no `tracking-[0.18em]`. All token-respecting.
