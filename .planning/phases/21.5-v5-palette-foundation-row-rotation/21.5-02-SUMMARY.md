# Phase 21.5 Plan 02: Row Rotation Mechanism Summary

**Continuous document-order accent rotation across Building and Writing homepage rows, computed server-side from shared row-derivation helpers and applied hover-only via a CSS custom-property fallback chain.**

## Performance

- **Duration:** ~45 min
- **Tasks:** 3/3 completed
- **Files modified:** 10 (5 modified, 5 created)

## Accomplishments
- `src/lib/accent-rotation.ts`: `ACCENT_COUNT`, `accentVar(index)`, `accentStyle(index)` -- the modulo-10 index-to-token mapping, negative-index-safe, zero hex values, zero React runtime dependency.
- `src/lib/homepage-rows.ts`: `buildingRows`/`writingRows` moved verbatim out of the two section components (identical behavior), plus `homepageAccentOffsets`, which derives the running counter from those same capped helpers so truncation and the offset math can never drift apart.
- `SectionBuilding`/`SectionWriting` now take an `accentStart` prop and set `style={accentStyle(accentStart + i)}` on every rendered `.a-row`/`.e-post`; `ExplorativeHomepage` computes `homepageAccentOffsets(projects, posts)` once and passes `building`/`writing` down. All three stay Server Components -- no `"use client"`, no hooks added.
- `.a-row::before`/`.e-post::before` now read `background: var(--ac, var(--color-invert))`, so an unset `--ac` (any future non-homepage reuse) degrades to the shipped ink fill rather than to transparent.
- `.e-post:hover`/`:focus-visible` `.dt`/`.rd` flip to full `--color-text-inverse` (bone) instead of the dim inverse, matching what 21.5-01's AA 4.5:1 proof was actually computed against.
- Reduced motion (both the media query and the `body.no-motion` escape hatch) now drops only the 150ms transition on both `::before` fills; the fill itself still applies on hover/focus per D-V5-10.
- `src/__tests__/home/accent-continuity.test.tsx` proves: per-section sequencing (Building 0-2, Writing 3-7 with `accentStart={3}`), the real cross-section 0..7 run with no repeats, the 0-project edge case (Writing starts at 1, not 0), and the wrap back to `--ac-0` past index 9.
