<objective>
Build the rotation mechanism: a continuous, document-order accent counter that runs across the
Building and Writing sections without resetting at a section head, applied on hover only.

Purpose: CSS `nth-child` cannot count across sibling `<section>` elements, so the counter has to be
computed in the orchestrator and handed down as a per-band start offset. This plan installs that
contract, wires it into the two row families, and points the existing hover fills at the palette
21.5-01 declared.
Output: two new server-safe lib modules, `accentStart`-aware Building and Writing sections, an
orchestrator that computes offsets from the same helpers the sections render from, hover fills that
read `var(--ac)`, and a test that proves Writing starts at index 3 when Building rendered 3 rows.
</objective>
